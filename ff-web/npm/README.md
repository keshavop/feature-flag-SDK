# @keshavop/feature-flags

Feature flag SDK for the browser, built from the shared Kotlin Multiplatform core of
[feature-flag-SDK](https://github.com/keshavop/feature-flag-SDK).

> Early preview: the evaluation API lands in upcoming releases. See the project
> [design docs](https://github.com/keshavop/feature-flag-SDK/tree/main/docs).

```js
import { sdkVersion } from "@keshavop/feature-flags";

console.log(sdkVersion());
```
